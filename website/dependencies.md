# react-arborist (current version: ^3.16.0)

## Purpose:

Allows for improved nesting features utilized on the Edit Toc page. Previous DND package did not support drag and drop of created cells to further nest them. Arborist sacrafices ghost rows for the aiblity to drag and drop chapters to nest.

## Adoption:

Isolated use in Edit TOC and does not impact the previous DND package which was left untouched.
